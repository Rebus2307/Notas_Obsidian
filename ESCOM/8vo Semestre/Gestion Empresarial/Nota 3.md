# Matriz BCG (Boston Consulting Group)

Herramienta para clasificar los productos o unidades de negocio de una empresa según dos variables:
- **Eje vertical:** Crecimiento del mercado (Alto / Bajo)
- **Eje horizontal:** Ventas / participación en el mercado (Alto a la izquierda, Bajo a la derecha)

## Los 4 cuadrantes

| Cuadrante | Crecimiento del mercado | Ventas | Característica | Estrategia |
|---|---|---|---|---|
| **Estrellas** | Alto | Alto | Generan buen desempeño y crecimiento | Crecer (seguir invirtiendo) |
| **Interrogantes** (`?`) | Alto | Bajo | Generan poco dinero / poca venta, pero están en un mercado en crecimiento | Analizar si conviene invertir en ellas para que se vuelvan estrellas |
| **Vacas** (vacas lecheras) | Bajo | Alto | Generan flujo de efectivo estable | Mantener y aprovechar el flujo que generan |
| **Perro** | Bajo | Bajo | Bajo crecimiento y bajas ventas | Desinvertir |

## Diagrama

```
                    VENTAS
              Alto  │  Bajo
         ┌──────────┼──────────┐
   Alto  │ ESTRELLAS│    ?     │
CRECI-   │ (crecer) │(Generan  │
MIENTO   │          │ poco     │
DEL      │          │ dinero/  │
MERCADO  │          │ ventas)  │
         ├──────────┼──────────┤
   Bajo  │  VACAS   │  PERRO   │
         │ (Generan │(desinver-│
         │ flujo de │  tir)    │
         │ efectivo)│          │
         └──────────┴──────────┘
```

> [!note] Idea central
> El ciclo natural de un producto suele ir de **interrogante** → **estrella** (si se invierte bien) → **vaca** (cuando el mercado madura y baja su crecimiento) → **perro** (cuando ya no genera valor y conviene desinvertir).
