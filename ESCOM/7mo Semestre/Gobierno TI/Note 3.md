# Cascada de Metas: COBIT 5 vs. COBIT 2019

## Cascada de Metas — COBIT 5

```
Motivos de las partes interesadas
(Entorno, evolución de la tecnología, ...)
            │
            ▼
Necesidades de las partes interesadas
 • Realización de beneficios
 • Optimización de riesgos
 • Optimización de recursos
            │
            ▼
      Metas corporativas
            │
            ▼
 Metas relacionadas con las TI
            │
            ▼
   Metas de los catalizadores
```

## Cascada de Metas — COBIT 2019

```
Impulsores y necesidades de las partes interesadas
            │
            ▼
         Metas corporativas
            │
            ▼
         Metas de Alineación
            │
            ▼
   Objetivos de gobierno y gestión
```

# Mapa Estratégico (diagrama de árbol)

**Meta financiera de ejemplo:** Incrementar las ventas en un 15% para el 1er trimestre de 2027

> [!note] Nota
> El mapa estratégico tiene que verse como un **diagrama de árbol**: la meta financiera en la parte superior, y hacia abajo se despliegan las dimensiones que la hacen posible (relación causa-efecto).

```
                    Incrementar las ventas en un 15%
                      para el 1er trimestre de 2027
                              (Financiera)
                                   │
                                   ▼
                              (Cliente)
                                   │
                                   ▼
                              (Interno)
                                   │
                                   ▼
                    (Aprendizaje y crecimiento)
```
