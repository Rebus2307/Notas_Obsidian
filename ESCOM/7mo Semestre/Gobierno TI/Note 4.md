# Objetivos de Gobierno o Gestión (40 en total)

Cada uno de los **40 objetivos** de gobierno o gestión de COBIT 2019 se compone de:

```
Objetivo de Gobierno o Gestión
            │
            ▼
Propósito del Objetivo
  con Metas Empresariales
  de Alineación y Métricas
            │
            ▼
      A: Proceso
```

## Ejemplos de Objetivos de Gestión
- **BAI11** — *Managed Projects*
- **MEA04** — *Managed Assurance*

# Sistema de Gobierno — Componentes

El **sistema de gobierno** de COBIT 2019 está formado por 7 componentes:

1. **Procesos**
2. **Estructuras organizacionales**
3. **Principios, políticas y procedimientos**
4. **Información**
5. **Cultura, ética y comportamiento**
6. **Personas, habilidades y competencias**
7. **Servicios, infraestructura y aplicaciones**
