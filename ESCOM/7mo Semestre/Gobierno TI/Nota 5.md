# Ciclo de Vida de la Implementación del Marco COBIT

El ciclo de vida de implementación de COBIT se mantiene igual a lo largo de las versiones del marco, y se representa mediante **3 círculos concéntricos**:

```
        ┌───────────────────────────────────────┐
        │   Gestión del Programa (círculo externo)│
        │   ┌───────────────────────────────┐     │
        │   │ Habilitación del Cambio         │     │
        │   │  (círculo intermedio)           │     │
        │   │   ┌───────────────────────┐     │     │
        │   │   │  Ciclo de Mejora       │     │     │
        │   │   │  Continua (círculo     │     │     │
        │   │   │  interno)              │     │     │
        │   │   └───────────────────────┘     │     │
        │   └───────────────────────────────┘     │
        └───────────────────────────────────────┘
```

Los 3 círculos representan de forma simultánea:
1. **Círculo interno — Ciclo de Mejora Continua:** las fases propias de la implementación (diagnóstico, diseño, ejecución y mejora).
2. **Círculo intermedio — Habilitación del Cambio:** la gestión del cambio organizacional necesario para que la implementación tenga éxito.
3. **Círculo externo — Gestión del Programa:** la administración del proyecto/programa de implementación en su conjunto.
